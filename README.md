# Fraud Detection, Credit Risk & Compliance Search

**Repo name on GitHub:** `fraud-detection-credit-risk`
**Context:** AI/ML Engineer @ U.S. Bank, Minneapolis, MN (Jul 2021 – Nov 2022)

> Case study of production work. This repo describes the system design and results — it contains no employer code or data.

## What it is
Machine learning systems for credit risk, transaction fraud detection, and compliance knowledge retrieval in a large-scale financial services environment.

## What I built
- Credit risk and customer behavior models on 50TB+ of transaction data
- scikit-learn classification models for fraud detection and transaction risk assessment
- Customer segmentation models for marketing effectiveness
- NLP classification automating 50,000+ monthly compliance documents
- Embedding-based semantic search and RAG prototypes over 10,000+ internal policy pages
- Docker-containerized inference services integrated via REST APIs (1,000+ calls/min)

## Results
- **$2.5M** in potential fraudulent activity flagged
- **-9%** default risk exposure
- **0.89 average F1-score** (ROC-AUC, precision, recall evaluation)
- **+35%** compliance search relevancy · **+12%** marketing conversion · **+7%** recall from tuning
- **-30%** deployment time through containerization

## Tech stack
Python · scikit-learn · Pandas · NumPy · AWS SageMaker · MLflow · SQL Server · Docker · REST APIs · Power BI

## Skills demonstrated
Fraud detection · Credit risk modeling · Financial NLP · Semantic search / RAG · Model evaluation & tuning
